# Sales Data Analysis Using Python

## Project Overview
This project analyses a sample retail sales dataset using Python to understand product sales and revenue performance.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Google Colab

## Key Findings
- Laptops generated the highest total revenue in the sample dataset.
- Mice had the highest number of units sold.
- Revenue and sales volume provide different perspectives on product performance.

## Project Features
- Created and analysed a structured sales dataset.
- Checked data quality.
- Calculated product-level revenue.
- Compared products by revenue and units sold.
- Created a visualisation of revenue by product.

## Limitations
This project uses illustrative sample data, not real business records. It does not include costs, profit margins, dates, or customer information.

## Skills Demonstrated
Python programming, data analysis, data cleaning, summary statistics, and data visualisation.
